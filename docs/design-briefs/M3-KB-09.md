## 2. 决策卡（2026-11-13 用户拍板，全按推荐）

### 卡 0 · 拆分 → **A：3 PR**（09A 后端基座 / 09B 后端检索面 / 09C 前端）
09A 独立成立（门禁 fail-closed 先落地、TD-302 收口）；09B 解析器+视角成块；09C 沿 A/B 先例。中间态风险评估：09A 合并后（09B 前）检索面不过滤——暴露面仅管理端诊断（`school.kb.view_chunks` 特权面），C 端检索在 M4；门禁已保证确认态，无安全回退。

### 卡 1 · ACL 状态模型与双门禁 → **D1-A**
状态 = audiences 行数 × `acl_confirmed_at/by`（null=未确认）；**PUT=全量替换且置未确认**；**confirm=置 by/at+审计**；已确认再 confirm → 409 `ACL_ALREADY_CONFIRMED`。构建创建（`service.py:2029` 判据链 `KB_NOT_APPROVED` 后）与发布（`TEST_PASSED` 门禁后）**同形**加：0 条 → 409 `ACL_REQUIRED`；非空未确认 → 409 `ACL_UNCONFIRMED`（拒绝审计沿 KB-02 既有构建门禁拒绝形态、零副作用）。执行期 `build_task` 取件后二次校验 → FAILED `ACL_UNCONFIRMED`（可重试）。下线/回滚/删除不受 ACL 门禁影响。

### 卡 2 · 检索过滤口径 → **D2-B：payload `acl_tokens` 单一事实源 + 变更即时同步**
构建写入逐 chunk `acl_tokens`；**PUT（置未确认）→ 已构建版本 `set_payload` 清空 acl_tokens（恒不召回 fail-closed）；confirm → `set_payload` 写新 tokens**（`mark_published_payload` 同形先例，service 层）；**查询 filter = `MatchAny(用户 tokens)` over payload `acl_tokens`（min_should=1）**，`search_points` 加 filter 参数单点下沉。收紧/放宽/重确认全部即时（set_payload 承担 spec :87）；查询路径零 DB 依赖（TD-098 缓存归 M4 chat）。落选 D2-A（filter 用当前 DB ACL 匹配 payload）：重确认/放宽后快照与配置错位、合法用户也不召回直到重构建，违反即时生效正向语义。已知边界（登记 §6）：DB 提交与 set_payload 非原子，毫秒级窗口旧 token（与发布侧 payload 翻转同形）；set_payload 失败 → 请求 502 `AUDIENCE_SYNC_FAILED`（DB 已提交，重试 PUT+confirm 恢复）。
**用户 token 解析**（09B）：`department:<id>`（自身部门+**祖先链**（物化路径前缀）→「父部门配置→子成员命中」）+ `role:<id>` + `class:<id>`（教师任教/班主任+学生班级）+ `grade:<值>` + `course:<id>` + `user:<self>` + **恒注入 `all`**；实时解析（无缓存）；解析异常=fail-closed 不召回（不发起查询）。

### 卡 3 · 沙箱与诊断视角 → **D3-A**（design :583 明文）
检索测试默认**操作者自身视角**；`as_user_id`/`as_audiences` 可选（`school.kb.view_chunks` 持有人；服务端校验 as_user 同租）；`ignore_acl=true` 仅 `school.kb.retrieval_test.unfiltered`（已有码）+强制审计；响应每候选块带回命中 token（可解释召回）。批量运行默认操作者视角+可选 `as_audiences`（milestone「沙箱人群视角」）；不加 ignore_acl（判分宁严勿松）。落选「批量默认全量视角」——与检索测试口径割裂，夹具配 `all` 后两者等价。

### 卡 4 · 既有测试回归策略 → **`all` 统一配置**
kb_env 加 `configure_audiences` helper（集成侧直落库 audiences+confirmed、业务/全栈侧 HTTP）；既有测试种子统一配 `all`+确认——配合卡 2 用户恒注入 `all`，**全部既有检索/对账断言零漂移**；只有新增 ACL 语义用例配具体人群。预估接线 ~10 文件每处 1-3 行；执行期二次校验使直落库种子（`_seed_approved_version`）也必须经 helper。

### 卡 5 · 工程事实（无争议项）
新迁移 1 个（`kb_document_audiences`+FORCE RLS+唯一约束 + `kb_document_versions.acl_confirmed_by/at` nullable）；无新权限码；新审计 2 动作（`school.kb.acl.updated`/`school.kb.acl.confirmed`——spec 的 `kb.acl.*` 按 house `school.kb.*` 前例理解）；新 error_code 3 个（`ACL_REQUIRED`/`ACL_UNCONFIRMED`/`ACL_ALREADY_CONFIRMED`）+1 个 502（`AUDIENCE_SYNC_FAILED`）；`audience_id` 用 **VARCHAR(64) NULL**（多态引用无 FK：UUID 存字符串、`grade` 存年级字符串——`classes.grade` 是 String(16)）；唯一约束 `(version_id, audience_type, audience_id)` 用 **`NULLS NOT DISTINCT`**（PG16；`all` 行 audience_id NULL 不得重复）。

## 3. 契约

### 3.1 KB-09A（本 PR 范围）

**迁移**（1 个）：`kb_document_audiences`（id/tenant_id/version_id FK/audience_type CHECK 7 值/audience_id VARCHAR(64) NULL/created_by/created_at + FORCE RLS + `UNIQUE NULLS NOT DISTINCT (version_id, audience_type, audience_id)`）+ `kb_document_versions` 加 `acl_confirmed_by UUID NULL`/`acl_confirmed_at timestamptz NULL`。downgrade 数据前提：无（新表可空降、新列可空）。

**API**（`app/api/school_kb.py` + `app/kb/service.py`）：

| 端点 | 权限 | 语义 |
|---|---|---|
| `GET /school/kb/document-versions/{version_id}/audiences` | `school.kb.view`（读侧先例 KB-08A 卡 1：配置信息非敏感） | 回包 `{version_id, audiences: [{audience_type, audience_id}], acl_confirmed: bool, acl_confirmed_by?, acl_confirmed_at?}`；跨租/不存在 404 `VERSION_NOT_FOUND` 同文不泄露 |
| `PUT .../audiences` | `school.kb.acl.manage` | 全量替换（空数组=清空→回未确认态）；校验：type 白名单、`all` 至多一条且不带 audience_id、非 `all` 必带 audience_id 且**同租存在**（departments/roles/classes/courses/users 按类型查；不存在/跨租 → 422 `AUDIENCE_NOT_FOUND` 人读码）；`all` 与其他类型互斥？**不互斥（并集语义）但 `all` 单独成档**——`all` 存在时其他条目冗余允许保留（并集等价）或 422 拒混？→ **422 `AUDIENCE_ALL_MIXED`**（显式拒绝混配，fail-closed 且语义清晰，重确认成本低）；成功=重写行集+清 confirmed_at/by+审计 `school.kb.acl.updated`（前后集合）+已构建版本 set_payload 清空 |
| `POST .../audiences/confirm` | `school.kb.acl.manage` | 前置：audiences 非空（空集 confirm → 409 `ACL_REQUIRED`）；已确认 → 409 `ACL_ALREADY_CONFIRMED`；成功=置 by/at+审计 `school.kb.acl.confirmed`（集合摘要）+已构建版本 set_payload 写 tokens |

**门禁**：构建创建（`service.py:2029` 判据链追加）与发布（`TEST_PASSED` 后）各加：audiences 空 → 409 `ACL_REQUIRED`+拒绝审计+零副作用；非空且 `acl_confirmed_at is null` → 409 `ACL_UNCONFIRMED`+拒绝审计。执行期（`build_task` 取件后）：同判据不过 → FAILED `ACL_UNCONFIRMED`。

**payload**：`build_payload` 加 `acl_tokens: list[str]`（十一字段；token=`f"{type}:{audience_id}"`、`all` 行→`"all"`；department 不展开子部门——展开在用户侧）；`build_task` 从已确认 audiences 读。payload 字段数变化同步 KB-03B 的 payload 断言测试。

**set_payload 同步**（service 层，`mark_published_payload` 同形）：`sync_acl_payload(client, collection, version_id, tokens)`——按 version_id filter 重写 `acl_tokens`；PUT 置未确认→`[]`；confirm→新 tokens；Qdrant 异常 → 502 `AUDIENCE_SYNC_FAILED`（DB 已提交；未构建版本〔collection 不存在〕跳过同步）。
