# 校园陪伴精灵 — 代码审查清单（code-review-checklist.md）

| 项 | 内容 |
|---|---|
| 版本 | v1.0 |
| 日期 | 2026-10-19 |
| 状态 | 待用户确认 |
| 规则 | 业务场景测试通过后审查；Blocker/Major 必须修复并复测；实质变更复审 |

---

## 1. 流程

1. 实现者完成 TDD（红→绿→重构），单元/集成测试通过。
2. 业务场景测试通过，业务输出断言满足。
3. 自动检查：ruff、mypy、ESLint、vue-tsc、bandit/pip-audit、pnpm audit、secret 扫描。
4. 独立 review agent/独立上下文审查 staged diff；不依赖实现者解释。
5. 输出 findings（Blocker/Major/Minor），写入 `docs/review-log.md`。
6. Blocker/Major 修复；Minor 修复或书面说明。
7. 复测：受影响 + 全量单元/集成/业务场景；前端补 Playwright；AI 补评估。
8. 实质变更重新审查；无 Blocker/Major 才 commit。
9. 完成汇报含审查结论/修复/复测，以及“更好做法与技术债”章节：
   - 本次提出的替代方案/优化建议是否已登记 `docs/tech-debt.md`；
   - 每条 TD 是否有处置（已完成/已采纳/已延后/已拒绝）；
   - 无 TD 编号的“更好做法”按 Major 处理（禁止只口头说明）。

---

## 2. 严重级别

| 级别 | 定义 | 处理 |
|---|---|---|
| Blocker | 跨租泄露、越权写、密钥/PII 泄露、数据丢失、状态机破坏、生产开关可绕过、审计缺失 | 立即修复，阻塞发布 |
| Major | 业务输出错误、关键测试缺失、性能明显退化、错误处理缺失、幂等/并发缺陷 | 必须修复并复测 |
| Minor | 命名/文档/样式/非关键体验/可维护性 | 修复或书面说明 |

**安全/租户/权限/状态机/数据一致性/AI 护栏/Langfuse 脱敏问题一律按 Blocker/Major。**

## 3. 审查清单

### 3.1 需求与验收
- [ ] 实现与 spec 功能点/验收标准一致。
- [ ] 边界/空值/超长/非法输入有处理。
- [ ] 未实现的验收项已明确标注，不静默跳过。
- [ ] 文档/spec/design 同步。

### 3.2 多租户隔离
- [ ] 新表含 tenant_id、索引、RLS、唯一约束含 tenant_id。
- [ ] 查询走 TenantScopedRepository；原生 SQL 显式 tenant_id+参数化。
- [ ] 缓存 Key/MinIO Key/Qdrant collection 含租户边界。
- [ ] 跨租读写删测试覆盖；平台跨租二次授权+审计。
- [ ] 不泄露他租计数/存在性。

### 3.3 鉴权与数据范围
- [ ] 服务端鉴权；不信任前端 tenant_id/role。
- [ ] 权限点/数据范围正确；跨班级/跨课程拒绝。
- [ ] 敏感字段额外权限+理由+审计。
- [ ] 审批职责分离；自批拒绝；超管例外默认关。
- [ ] token 撤销/权限变更生效。

### 3.4 状态机/并发/幂等
- [ ] 状态流转守卫完整；非法流转 409/403。
- [ ] 写操作幂等键+唯一约束；重复请求一次效果。
- [ ] 并发审批/撤回/发布/删除无非法状态/丢失更新。
- [ ] 事务边界正确；失败回滚。
- [ ] 知识库构建/发布门禁正确（APPROVED/TEST_PASSED）。

### 3.5 输入安全
- [ ] SQL 参数化；禁止字符串拼接。
- [ ] XSS/HTML 净化；Markdown 渲染安全。
- [ ] 提示词注入防护；用户输入不直接拼系统提示词。
- [ ] 文件上传：白名单/魔数/大小/ZIP 炸弹/路径穿越/病毒扫描。
- [ ] 命令注入/SSRF/开放重定向检查（如涉及）。
- [ ] 长度/编码/类型边界。

### 3.6 输出安全
- [ ] 跨用户/跨租 PII、系统提示词、工具/密钥/内网地址过滤。
- [ ] 引用校验；伪造引用降级。
- [ ] 自伤/违法内容安全话术；不诊断。
- [ ] 思考摘要脱敏；无原始 CoT。
- [ ] Langfuse 默认无原文/PII/密钥。

### 3.7 错误处理/恢复
- [ ] 超时/重试/熔断/降级；无裸报错。
- [ ] LLM 流中失败标记部分回答；可重试。
- [ ] MinerU/ClamAV/Qdrant/Redis/邮件失败策略。
- [ ] 用户取消/断线处理。
- [ ] 生产不暴露堆栈/内网地址。

### 3.8 性能
- [ ] 无 N+1/重复查询；索引合理。
- [ ] 无阻塞调用/低效循环/内存泄漏。
- [ ] 分页/虚拟滚动；大文档/大列表。
- [ ] SSE 心跳/背压/取消。
- [ ] 缓存失效/版本 Key 正确。

### 3.9 测试质量
- [ ] 单元/集成/业务场景覆盖正常/边界/异常/权限/跨租。
- [ ] 业务场景断言最终业务输出，不只 HTTP 200。
- [ ] 测试数据清理；测试/生产隔离。
- [ ] 外部 mock 不进入生产路径。
- [ ] AI 功能有评估用例/阈值。

### 3.10 文档与可维护性
- [ ] 中文 docstring（用途/参数/返回/异常）。
- [ ] 模块化/低耦合/无重复。
- [ ] 配置化/无硬编码；提示词版本化。
- [ ] 日志/审计/trace 有 request_id/租户，无敏感信息。
- [ ] 迁移脚本/回滚/索引。

### 3.11 前端
- [ ] 权限菜单/按钮只是 UX；服务端仍鉴权。
- [ ] SSE 事件处理/停止/重连/错误。
- [ ] 思考开关/脱敏；引用抽屉。
- [ ] 移动端安全区/弱网/降级。
- [ ] XSS/CSP；不存敏感数据在 localStorage。

### 3.12 Langfuse（涉及观测）
- [ ] 本地 trace 必发；Langfuse 关闭不报错。
- [ ] 映射正确；tenant_hash/user_hash。
- [ ] 场景采集白名单；同意/删除/匿名化。
- [ ] 脱敏；无系统提示词/工具 schema/密钥。
- [ ] 异步/有界队列/故障隔离。
- [ ] Prompt Git 源；无运行时依赖。

## 4. 高风险功能（必须人工复审）

- 认证/令牌/密码/MFA。
- 租户隔离/RLS/仓储过滤。
- 权限矩阵/数据范围/审批分权。
- 账号删除/撤权 5 天状态机/冻结/证明。
- 知识库审批/构建进度/分块/发布/蓝绿/回滚。
- 加密/密钥/文件上传/MinerU 适配。
- AI 输入/输出护栏/工具执行/SSE/多意图。
- Langfuse 数据外送/脱敏/访问控制。
- 配置变更/双人确认/break-glass。
- 备份/恢复/删除证明。
